# 根音测出来了，又在最后一步被丢掉（2026-11-09，OPN ADPCM-B / MIDI）

**现象（按用户报告的顺序）**

1. 打开「根据采样根音移调」，MIDI 输出**毫无变化**；
2. 修好之后，`07 Stage 2` 基本正确，`04 Stage 1` **只有一半音符正确**；
3. 再修之后，几乎全部正确，但仍有音符差**半个到 1 个半音**，重音头的失真吉他尤其明显；
4. 关掉开关，**感觉移调仍然生效**。

四个现象不是四个 bug，而是同一条链上的五个缺陷依次暴露。

---

## 一、缺陷与证据

| # | 缺陷 | 证据 | 修法 |
|---|---|---|---|
| 1 | MIDI 路径把 `0x82` 写死当 DeltaT 镜像，且每族只建一份 | OPNB 的 DeltaT 在 `0x83`，于是周期从 ADPCM-A 字节量出 | `OpnDecoder::sampleBlocksFor(variant)` 成为唯一定义，`flushOpn` 按设备取镜像 |
| 2 | 镜像按**内容末尾**裁剪（`clipToContent = true`） | `07 Stage 2` 被裁到 6.96 MB，而寄存器地址到 `0x6B9000` → 上方字节读 0 → **周期全部为 0** | 与播放路径同一条规则：按声明大小装 |
| 3 | 周期只从**样本起点**测 | `04 Stage 1` 540/803 个 key-on 测不到周期（起点是起音噪声） | 起点失败后再试 +1 KB、+2 KB（`0x570100`：无 / 127.30 / 126.99） |
| 4 | 音符取整后的**余数被丢弃**（只加进“恰好存在的弯音”） | 实测根音 −1444 / −2630 / −2039 → 余数 −44 / −30 / −39 音分被静默吞掉 | 无弯音时单独发一条起点弯音；已被合并的从待发表移除，避免重复 |
| 5 | 重载依赖**磁盘上的文件仍然存在** | `reloadForPitchChange()` 以 `loadedFile.existsAsFile()` 为前提；文件来自临时目录或已移动时提前返回，旧序列继续播放 | 改为用引擎内存里的镜像重建（`selectSongAsync`），位置与播放状态自行恢复 |

## 二、为什么走了这么多步：每修一层，才看得见下一层

```
①块类型错  → 周期永远 0        → 开关完全无效（现象 1）
②镜像被裁  → 周期仍然 0        → 修了①仍无效，看上去“没修好”
③起点有噪声 → 一部分周期为 0   → 一半音符正确、一半漂移（现象 2）
④余数被丢  → 全部音符偏 ≤50 音分 → “差半个到 1 个半音”（现象 3）
⑤重载看磁盘 → 关闭时旧序列留着   → “关掉了还生效”（现象 4）
```

这也是本轮最贵的一课：**根因不是并列的，而是串联的**。修掉一层后必须**重新测量**，否则会把“仍然无效”误判为“修错了”。

## 三、方法：把编码器拿到的数字打出来

- `MIDI_TRACE` 打印每个 ADPCM-B 音符的 `note / rootCents / pitchSource`（临时）；
- `OPN_TRACE` 打印每次 key-on 的 `start / delta / cycleLength`（临时）；
- `OPN_TRACE2` 在每个周期搜索失败处打印 0 / +1 KB / +2 KB 三个窗口的结果——这一条直接给出了“起点是起音、音身在后”的结论；
- 对照可视化：同一时刻探针的 `note / hz` 与 MIDI 的 `note + root` 必须一致（实测 1.54 s：70 / 465.8 Hz ↔ 84 − 1444 音分）。

**判据**：两套路径（可视化走 `hz`，MIDI 走 `L1 + rootCents`）必须给出同一个音高；不一致的地方就是缺陷所在，而不是“两边各自合理”。

## 四、教训

1. **“开关没作用”先怀疑数据，不怀疑开关。** 打开与关闭产出同样的音符，说明喂给它的 `rootCents` 恒为 0，而不是 UI 没接线。
2. **同一份事实只能一条规则。** 本轮又出现两次：DeltaT 的块类型（解码器 vs MIDI 构建器）、镜像大小（播放用声明大小、MIDI 用内容末尾）。规则第 13 条写的就是这个，仍然会以新面孔出现。
3. **算法精度不是默认嫌疑人。** 用户怀疑“根音分析算法”，但 `estimateCycleLength()` 早就有抛物线插值（几个音分）；真正的误差来自**最后一步把结果丢了**。先查“结果有没有被用上”，再谈“算法准不准”。
4. **起音不是样本。** 打击类样本的头 1 KB 是噪声；周期要往后找。任何“按起点取窗口”的分析都要问一句：起点是内容，还是包络？
5. **临时诊断要可拆。** 三个 `*_TRACE` 都是环境变量开关，验证完立即删除；留下的只有断言的数字结论。
6. **重载路径不要依赖“文件还在”。** 引擎已经持有镜像，重建应当用它；磁盘只是最初一次读取。
