# NSF 的直流偏置：四次尝试与一个结构性问题

日期：2026-10-25
状态：**暂缓**。四次实现均已回退，工作区干净，没有任何未完成的代码。
相关：`docs/review/2026-10-25-nsf-playback-experience.md`

## 1. 现象

任何 NSF（含纯 2A03 的文件）在混音器里，`Triangle` 轨都会报出一个恒定 RMS：

```
fds_song.nsf（只有 FDS 发声）
  Triangle   rms = 0.14695      ← 三角波从未播放
  FDS        rms = 0.04711
```

`0.147 ≈ −16.7 dBFS`，相当于恒定占用 15% 满量程。`1983.nsf` 的开头曾被误判为“三角波在演奏”，实际全是这个电平。

## 2. 根因（都在芯片核中）

1. `nes_dmc.cpp` 的 `calc_tri` 无条件返回 `tritbl[tphase]`，即使 length/linear counter 为 0——**DAC 保持电平**（真机行为）；
2. 非线性混音表在三个通道全静音时，`tnd_table[1][0][0][0]` 不是 0。

真机靠**输出电容**去掉它；我们这条链是直流耦合。

## 3. 四次尝试

| # | 做法 | 结果 | 失败原因 |
|---|---|---|---|
| 1 | 芯片核里把关闭的三角波输出改成 0 | 静音归零 | **起音 click**：每次从 0 跳到保持电平 |
| 2 | 引擎输出级 5 Hz 高通（状态从 0 起） | 无 click | 每次加载/跳转 **150 ms“噗”**；0.5 s 窗口均值反向过冲（k053260：`0.0987 → −0.0537`） |
| 3 | 同上 + 20 ms 淡入 | 同上 | 只是掩盖瞬态，均值仍偏 |
| 4 | 播放器内**按块**跟踪并扣除（逐通道 + 总和两条路径） | 静音真归零（`fds_song` 全 0，FDS 0.04711），无瞬态 | **打破“各轨求和 == 直通混音”**：逐通道扣除与按总和扣除收敛到不同电平，静音/独奏时两条路径不再等价 |

第 4 次的失败最值得记住，因为它通过了“好听”的检验却破坏了不变量：

```
FAIL  the unity-gain sum matches the plain mix (< 0.5 dB)
FAIL  switching the mixer off restores the plain mix
```

## 4. 为什么难：三个条件无法同时满足

| 条件 | 尝试 1–3 | 尝试 4 |
|---|---|---|
| ① 两条渲染路径等价（混音求和 == 直通） | ✅ | ❌ |
| ② 无启动/跳转瞬态 | ❌ | ✅ |
| ③ 不改变通道间可听平衡 | 部分 | ✅ |

要同时满足 ①②，去直流必须发生在**求和之后**且**状态可预置**的位置；而现在直通与混音的求和点是两个不同的位置，没有共同的后处理点。**这是结构问题，不是参数问题。**

## 5. 将来的做法（建议）

1. **先把两条渲染路径的后处理点统一**（一次独立重构）：所有后端都经过同一个“最终总线”位置，混音与直通在那里汇合；
2. 在该点做直流阻断，并支持**状态预置**（用进入该点前最后一个块的平均电平初始化），从而无瞬态；
3. 用**已知静音窗口**度量直流，而不是整段均值——音乐的自身不对称（ga20 的 `−0.0195`）与直流同量级，用均值当判据无法区分“移除了直流”和“挪动了直流”。

## 6. 验收标准（将来实现时）

- [ ] `fds_song.nsf`、`mmc5_song.nsf`、`fme7_song.nsf` 里，非发声轨的 RMS < 1e-4，且混音 RMS ⊂ 发声轨；
- [ ] `Entry080.nsf` 的三角波轨在“音乐段落”的**峰值**不变（±1%），RMS 因去直流而下降属于预期；
- [ ] `[3]` 的“各轨求和 == 直通混音（< 0.5 dB）”在所有 NSF 用例上通过；
- [ ] 加载、跳转、solo 切换三种时机均无 > −40 dBFS 的瞬态（用一段静音前后的峰值检查）；
- [ ] MMC5 / FME7 的两份手工资源并入 ctest。

## 7. 影响现状（暂缓期间的已知行为）

- 听感：**无影响**（直流不可闻），用户实测音量与音色均正常；
- 数值：静音轨的 RMS/表头有固定底数；`1983.nsf` 这类开头静音的曲子在该轨读数上像“正在播放”；
- 测试：套件里“静音所有芯片应当无声”的断言对含 2A03 的文件不成立，因此 **MMC5 / FME7 的两份资源仅手工验证，未进 CI**；
- 动态余量：恒定占用约 15% 满量程。
