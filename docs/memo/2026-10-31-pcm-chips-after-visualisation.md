# 其余 PCM 芯片的采样导出，等 VGM 可视化之后再做

**日期**：2026-10-31
**状态**：待办（不是放弃）
**相关**：`docs/desgin/pcm-sample-export.md`、分支 `feature/pcm-sample-export`

## 决定

**这一轮只做 2A03 的 DPCM**，NSF 与 VGM/VGZ 两条入口都已接上。**其余 11 个 PCM 解码器（SegaPCM、OKI6295、K054539、C140、RF5C68、RF5C164、PWM、ES5503、ES5506、X1-010、C352）的采样导出，等 VGM/VGZ 的可视化输出完成之后再逐个接。**

## 为什么不是现在

**因为它们的采样数据组织方式彼此不同，而且没有一种能靠“读一遍寄存器”推出来。**

2A03 的 DPCM 之所以这一轮就能做，是因为它的地址和长度**全部在寄存器里**（`$4012`、`$4013`、`$4015`），而数据在 `0x67` 块里带着地址。两半都是现成的。

其余芯片不是：

| 芯片 | 采样怎么定位 |
|---|---|
| SegaPCM | `$C0` bank + start/end 地址寄存器，两者都要解码 |
| OKI6295 | 4 个 voice 的 start/stop，地址是 16 位但要按芯片的 ROM 布局换算 |
| K054539 / C140 | 256 项**静态表**，每项含起始地址与长度，表本身也在 ROM 里 |
| RF5C68 / RF5C164 | 内部 RAM，采样由 `0x67` 写入，但地址空间和映射要单独解释 |

**共同点是：光有寄存器不够，还得知道那颗芯片怎么把“寄存器值”折成 ROM 偏移。** 这需要对着片子调，而不是照着规范写一遍。

## 为什么等可视化

**可视化的作用是把“我读到的字节”和“它应该是什么声音”摆在同一个屏幕上。**

这一轮 2A03 的每一步都是这样验的：先看波形，再对 FamiStudio 的导出，最后才敢说对。**没有画面，调试这 11 个芯片只能靠猜波形和听声音**，而这两件事在有 11 个芯片要接的时候都太慢了。

**先有画面，再逐个接**，每个芯片的验收标准也跟着清楚：波形对得上、长度对得上、速率对得上。

## 已经为它们留好的位置

```
ITrackPlayer::samples()          ← 每个后端的播放器覆盖它
playback::DecodedSample          ← 电平 + 速率 + 名字，不含芯片知识
playback::writeSamples()         ← 只写文件
```

**加一颗芯片 = 一个 `collectXxxSamples()` + 一次 `setSamples()`。** 导出层、菜单、报告浮层都不用改。

`NesDpcmBank.cpp` 就是那个形状的样板：**十四行接口，两百行实现，其余全部复用**。

**它属于芯片，不属于某个格式**，应该在 `chips/` 或 `playback/` 下。移过去是一次重命名加四处源文件列表，**下一次碰这块时顺手做掉**。
