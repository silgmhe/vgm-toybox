- **状态**：已实现（Q1 下部 1/3、Q2 琴床+高斯阴影、Q3 圆角统一 8、Q4 与 Mixer 同尺寸 28、Q5 1px 下沉；音名加粗）
- **日期**：2026-10-24
- **依据**：用户截图与五条反馈 + 按键按压反馈
- **涉及**：`plugin/Source/ui/ContentSlot.cpp` → `ContentSlot::KeyboardPanel`

| A | 按下的琴键要"凹下去"，阴影不能被裁 | 成立，且是当前最缺的质感 | 内阴影 + 1 px 下沉，全部画在键内 |

| 5 | Meter 与键盘间距太近 | 成立：现在 10 px | 改为 **18 px** |

## 2. 问题 2 是根因

截图里白键"看不见"，不是颜色选错了，而是**白键与卡片底色几乎同色**：

```cpp
// 现在
whiteKey = theme::card().interpolatedWith (theme::primaryText(), 0.09f);
// 卡片背景也是 theme::card()
```

9% 的墨色在浅色主题下几乎看不出，黑键又太重（74%），于是画面变成"一排黑块浮在空白上"。

**改法分两层**：

1. **琴床**：键盘区域先铺一条比卡片略深的底（`theme::track()` 或 card 加深 6%），边界用 1 px 描边，内侧再压一层 1 px 的极淡内阴影 —— 白键就有了"落在凹槽里"的参照；
2. **白键**：不透明、比琴床亮一档（深色主题下就是 #2E2E33 一类的实色），键与键之间留 **1 px** 缝隙，缝隙露出琴床色，白键的轮廓自然就出来了。

黑键降到 **62%** 墨色，宽度保持 0.62 倍白键、高度 0.62 倍行高 —— 与白键的明度差约 40%，不再是"两块黑砖"。

## 3. 行布局（新数字）

```
┌ tile ─────────────────────────────────────────────────────────────────────┐
│ ←14 名称 72 ─8─ [M][S] 30×24 ─8─ 音高 56 ─8─ 波形 88 ─10─ 键盘 … ─18─ Meter 96 ─14→ │
└───────────────────────────────────────────────────────────────────────────┘
```

| 元素 | 现在 | 改为 |
|---|---|---|
| 行内左内缩 | 0 | **14** |
| M/S | 26 宽、上下各内缩 6 | **30 × 24**，间距 8 |
| 音高列 | 56 | 56（不变） |
| 波形列 | 88 | 88（不变） |
| 键盘 → Meter | 10 | **18** |
| Meter 右内缩 | 0 | **14** |
| 圆角 | 行 8 / 组头 3 | **统一 8** |

行高维持 **40 px**（M/S 24 px 在其中垂直居中，上下各留 8 px）。

## 4. 按压态（反馈 A）

按下时三件事同时发生，都在键的矩形内完成：

| 层 | 画法 |
|---|---|
| 底面 | 由白键色压暗 8%（黑键压暗 12%） |
| 内阴影 | 顶部 4 px 由 `rgba(0,0,0,0.28)` 渐隐到透明；左/右各 2 px 同样的极淡渐变 |
| 下沉 | 整个键（含音名）**下移 1 px**，底部补 1 px 亮线 |

**不裁切**：内阴影只画在键的 `fillRoundedRectangle` 之后、以键的内缩矩形为 clip，天然不会溢出；行级的 clip 只裁到 tile 外，因此按键四周的投影不会被切。

**离键的一刻**：不做弹起动画。键盘以 30 Hz 刷新，动画会与真实按键时间错开，反而显得迟滞。

## 5. 音名位置（反馈 B，待确认）

现在音名画在**键的正中**，与下方的八度标记（C2/C3…）在同一竖线附近，一个 C 键上会出现两个文字。

建议：

| 情形 | 位置 |
|---|---|
| 一般按键 | 键的正中（垂直居中） |
| 正在发声的按键 | **键的下部 1/3**（黑键则在键的下沿之下、白键区域），避免与顶部黑键重叠 |
| 该键同时是 C | 只画音名，八度标记让位（已有规则） |

字号 9 px，粗体；按压时下移 1 px 随键一起。
