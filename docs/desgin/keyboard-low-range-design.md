# 键盘视图：低于 C2 的音怎么办

- **状态**：设计稿，待评审
- **日期**：2026-10-24
- **前提**：箭头已改为左右指向（`3b813ff`）；本稿只解决"音域窗口从哪开始"

## 1. 问题

键盘窗口的左边界固定 C2（MIDI 36）。**2A03 的三角声道常年在 C1–C3 走低音**，那部分音符没有键可亮，只有一个左箭头。

这在实际曲子里不是边缘情况：`Entry025.nsf` 的三角是 G3，但同类曲子（尤其低音线明显的）会到 C1。

窗口宽度换算成八度是有限的：

| 窗口宽 | 八度 | 固定从 C2 起 | 代价 |
|---|---|---|---|
| 900 | 3 | C2–B4 | C1、C5 以上看不到 |
| 1100 | 4 | C2–B5 | C1 看不到 |
| 1500 | 7 | C2–B8 | 基本够，但顶端是空的 |

## 2. 四种做法与取舍

| 方案 | 做法 | 优点 | 问题 |
|---|---|---|---|
| **A. 起始音设置** | 设置里选 C1 / C2 / C3 | 简单、可预测 | 全局一个值，无法同时对一首低音歌和一首高音歌都合适 |
| **B. 按歌自动适配** | 观察这首歌实际用到的音域，把窗口对齐到它 | 每首歌都贴合；无抖动 | 需要"只扩不缩"否则会来回跳；开头几秒还在观察 |
| **C. 实时跟音平移** | 音在窗外就把窗口挪过去 | 永远看得到当前音 | **否决**：13 行各自平移，横向比较立刻失效，且画面持续晃动 |
| **D. 每行独立音域** | 每个通道按自己用到的音域定窗口 | 每行都最紧凑 | **否决**：两行的 C3 会落在不同位置，"谁的音更高"看不出来 |

## 3. 建议：B + A + 手动平移

### 3.1 自动适配（只扩不缩）

```
观察：每个通道出现过的音（note 值）
取   ：minNote / maxNote
窗口：以八度为粒度，尽量覆盖 [minNote, maxNote]
     └ 若跨度过大（> 当前可见八度数），改为以中位数为中心
规则：只扩不缩；换歌时重置
```

为什么"只扩不缩"：一首歌里低音偶尔出现一次，若窗口随之上下移动，整页会不断跳动。**扩一次就停住**，比精确跟随更可读。

### 3.2 起始音设置（自动之外的兜底）

| 值 | 说明 |
|---|---|
| **自动**（默认） | 按 §3.1 |
| **C1 / C2 / C3** | 固定左边界，给喜欢稳定参照的人 |

选择固定值时不再自动适配——用户已经明确指定了参照。

### 3.3 手动平移

两个入口，都作用于**所有行**（保持同一参照）：

- **Ctrl + 滚轮**：每次一个八度；
- **点击左右箭头**：向箭头方向平移一个八度。

手动平移后，这首歌内不再自动适配（直到换歌）。

### 3.4 箭头继续存在

自动适配之后仍可能超出（音域跨度大于可见八度数）。此时箭头照旧，作用从"提示"升级为"按钮"——点它就能去看。

## 4. 界面变化

设置 → 键盘，新增一行：

```
起始音        [ 自动 ▾ ]        C1   C2   C3
[✓] 音符超出可见键位时显示箭头
```

无其它可见变化；键盘行布局不动。

## 5. 实现

| 步 | 内容 |
|---|---|
| 1 | `KeyboardPanel` 记录 `observedMin/observedMax`，在 `setSnapshot()` 里累积（只扩） |
| 2 | `baseNote` 由「设置值」或「observed 拟合」决定，八度对齐 |
| 3 | `paintKeyboard` 用 `baseNote` 取代常量 `firstNote = 36` |
| 4 | Ctrl+滚轮 / 点击箭头 → `baseNote` 平移一个八度，并置 `manual = true` |
| 5 | 设置页加「起始音」下拉；`songChanged()` 时重置观察与手动标记 |

约 120 行，仍在 `ContentSlot.cpp` 与设置页内。

## 6. 风险

| 风险 | 处理 |
|---|---|
| 开头几秒窗口会变一次 | 只扩不缩，最多变一次；且首次适配延后 0.5 秒再定 |
| 手动平移后忘了回自动 | 换歌即恢复；设置里改回"自动"也恢复 |
| 八度对齐导致覆盖不足 | 对齐到 C，宁可多显示一个八度也不把 C 键错位 |
